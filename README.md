A poem about agency — "The Key in the Other Hand" — written by a program.
`main.py` (Python 3.13, standard library only) writes the poem to
`entry.txt`: the power to choose and to act, and the agency that passes
between hands when one acts for another.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Deterministic: the same bytes on every run, no network, no randomness.
